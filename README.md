skipping-meeting-excuse writes one line to a text file: an excuse for skipping a pointless meeting. The line was picked from 36 candidates by pairwise judging against the brief — a 90-minute meeting to pick a font, declined with a single word that does two jobs at once: it is the font picked, and the excuse itself. The program checks the result against the entry gate before writing it, then reads the file back to confirm the bytes match.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 93 characters, a single line, and ends on its strongest beat. The program checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
